# Model Artifacts

This folder is generated by running:

```bash
python -m src.train
```

It contains:

| File | Description |
|---|---|
| `student_success_model.joblib` | Final trained classifier |
| `preprocessor.joblib` | Fitted `ColumnTransformer` (scaling + one-hot encoding) |
| `label_encoder.joblib` | Maps `Dropout/Enrolled/Graduate` <-> integer labels |
| `metrics.json` | Validation comparison, test metrics, confusion matrix, classification report |
| `metadata.json` | Feature lists, class order, training timestamp |
| `feature_importance.csv` | Ranked feature importances (tree-based models) or coefficient magnitudes (linear models) |

**These files are committed to the repository on purpose** so that:
- The Streamlit app can be deployed directly without a training step at boot time.
- Anyone reviewing the project can inspect exact reported metrics without retraining.

To regenerate them (e.g. after changing features or adding data), just re-run
`python -m src.train` — it will overwrite all files in this folder.
